# ADR-009: License: Apache-2.0, no CLA

**Status:** Accepted
**Date:** 2026-11-07
**Implements:** RFC v3 §8 (Repository conventions), PR1

## Context

The project is open source from the first commit and may attract contributions. MIT and Apache-2.0 were both acceptable. The choice had to be made before PR1 so every file lands under one license.

## Decision

- Apache License, Version 2.0, with a `NOTICE` file. No Contributor License Agreement; the license's own contribution clause (section 5) governs contributions.

## Consequences

- Explicit patent grant and NOTICE handling.
- Contributors keep their copyright; the project cannot relicense without their consent.
